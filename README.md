# PI-ADO
ADO – Introdução a Orientação a Objetos

1. Crie um projeto em TypeScript no padrão “<SeuNomeSobreNome>ADO1”.
Ex: JoaoSilvaADO1
2. Escolha um animal que inicie com a mesma letra que seu nome (ex: Enzo – E):
Elefante, Esquilo, etc.
3. Defina uma propriedade nome e mais pelo menos duas propriedades de seu animal
(O que o seu animal possui) além do nome
4. Crie um construtor que receba o nome do animal.
5. Crie pelo menos dois métodos referentes ao que o seu animal possa fazer.
6. Instancie dois objetos da sua classe e exiba o nome dos animais criados.
